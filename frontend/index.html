使用说明

关于本应用与相关项目。

基本用法

1. 在左侧文本框输入要合成的内容（最长 8000 字符，Ctrl + Enter 快速生成）；
2. 在右侧选择语音，拖动滑块调整语速、音调、音量；
3. 点击「生成语音」，完成后即可在下方试听或下载 MP3。

相关项目

本项目的界面样式基于 WinUIonWeb 提取的 WinUI 设计令牌与控件样式； 语音合成能力来自 edge-tts（Microsoft Edge 在线 TTS 服务）。

  • 后端：Python · FastAPI · edge-tts（流式返回 MP3）
  • 前端：原生 HTML / CSS / JavaScript，无构建步骤
  • 主题：跟随系统 / 手动切换亮色与暗色
  • 许可：本项目以 GNU GPL-3.0 协议发布；界面样式源自 WinUIonWeb（GPL-3.0）
